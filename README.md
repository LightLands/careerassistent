## ✨ Возможности

| Функция | Описание |
| :--- | :--- |
| 🔍 **Умный поиск вакансий** | Агрегация актуальных удаленных предложений через Remote OK API. Гибкие фильтры по технологии, минимальной зарплате (в USD) и региону. |
| 📊 **Трекер откликов** | Сохраняйте понравившиеся вакансии в один клик. Отслеживайте статусы: `Сохранена` → `Отклик` → `Интервью` → `Оффер` / `Отказ`. Автоматическая статистика и расчет конверсии в интервью. |
| 🔔 **Умные уведомления** | Настройте персональную подписку (например, *"Python, от $90k, Europe"*). Бот ежедневно сканирует новые вакансии и присылает только релевантные. |
| ✉️ **Генератор Cover Letter** | Автоматическое создание профессиональных сопроводительных писем на английском языке на основе описания вакансии и вашего стека. |

## 🛠️ Технологический стек

- **Язык:** Python 3.12+
- **Бот-фреймворк:** [aiogram 3.x](https://docs.aiogram.dev/) — асинхронная архитектура
- **HTTP-клиент:** `aiohttp` — асинхронные запросы к внешним API
- **Парсинг:** `BeautifulSoup4` — очистка HTML-описаний вакансий
- **База данных:** `SQLite3` — хранение пользователей, вакансий, подписок и статусов откликов
- **Планировщик:** `APScheduler` — фоновая ежедневная проверка новых вакансий
- **Логирование:** `logging` — запись в консоль и ротируемый файл `bot.log`
