## ✨ Возможности

🔍 **Умный поиск вакансий**  
Агрегация актуальных удаленных вакансий через Remote OK API с гибкими фильтрами: технология, минимальная зарплата (в $), регион.

📊 **Трекер откликов и аналитика**  
Сохраняйте вакансии в один клик. Отслеживайте статусы: `Сохранена` → `Отклик` → `Интервью` → `Оффер` / `Отказ`. Бот строит статистику и показывает вашу конверсию в интервью.

🔔 **Умные уведомления**  
Оформите подписку на конкретные критерии (например, "Python, от $80k, Europe"). Бот будет проверять новые вакансии каждый день и присылать только релевантные предложения.

✉️ **Генератор сопроводительных писем**  
Создавайте профессиональные черновики Cover Letter на английском языке на основе описания вакансии и вашего опыта.

## 🛠️ Технологический стек

*   **Язык:** Python 3.12+
*   **Фреймворк бота:** [aiogram 3.x](https://docs.aiogram.dev/) (асинхронный, современный)
*   **Работа с сетью:** `aiohttp` (асинхронные HTTP-запросы к API)
*   **Парсинг:** `BeautifulSoup4` (очистка HTML-описаний вакансий)
*   **База данных:** `SQLite3` (хранение пользователей, вакансий и подписок)
*   **Планировщик:** `APScheduler` (фоновая ежедневная проверка новых вакансий)
*   **Логирование:** Встроенный модуль `logging` (запись в консоль и файл `bot.log`)
